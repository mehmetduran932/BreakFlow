1. Executive Overview & Problem Taxonomy

Generating enterprise-grade PDFs from standard HTML/CSS remains one of the most frustrating bottlenecks in modern software engineering. While modern browsers excel at dynamic screen layouts using Flexbox and Grid, the CSS Paged Media specifications and browser print engines exhibit severe semantic blind spots when converting viewport DOM trees into paginated sheets.

Common failures include orphaned section titles isolated at page bottoms, cards dissected between pages, table rows sliced midway, and unpredictable blank pages triggered by naive `break-inside: avoid` properties on tall elements.

4. Declarative API Configuration Example

Integration requires zero modification to host application frameworks (React, Angular, Vue):

import { createPaginator } from '@breakflow/browser';

const paginator = createPaginator({
  page: { format: 'A4', margin: '15mm' },
  smartDefaults: true,
  table: { repeatHeader: true, preventRowSplit: true }
});

// Analyze without altering the live DOM
const analysis = await paginator.analyze('#report-container');
console.log('Issues found:', analysis.issues);

// Perform intelligent pagination
const result = await paginator.paginate('#report-container');
