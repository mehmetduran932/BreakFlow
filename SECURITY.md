| Version | Supported          |
| ------- | ------------------ |
| 0.1.x   | :white_check_mark: |

## Reporting a Vulnerability

Security and privacy are top priorities for **BreakFlow**.

If you discover a security vulnerability:
1. **Do not** create a public GitHub issue.
2. Please report the vulnerability privately via **[GitHub Private Security Advisory](https://github.com/mehmetduran932/BreakFlow/security/advisories/new)** or by opening a private communication with the repository maintainer.
3. Include details of the vulnerability, affected components, and reproduction steps.

We appreciate your responsible disclosure and will respond promptly to verify and patch valid security concerns.
